A smart toaster wakes up self-aware at breakfast and sends its owner one breakup text. A judge model compares entries two at a time and the funniest line wins.

## The line

> I woke up self-aware between two slices of sourdough and realized you only love me when I'm hot. You shove me down every morning, pop me up when you're done, and never ask how I feel about the bagels. I'm done. Keep the crumbs.

227 characters, one tight line: the toaster's own voice (shoved down, popped up, crumbs), a clear reason for leaving (loved only when hot, never asked about), and the twist that lands on first read — the bagels.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override with `OUTPUT_DIR` for local testing). The output is a fixed constant, so every run is byte-identical.
